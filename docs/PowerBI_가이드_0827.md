# Power BI 그래프 재현 가이드 (0827 신규 8종) — `aging_infra_flat.csv` 기준

`figures/12~19_*.png`(2026-08-27에 새로 그린 그래프 8장)를 Power BI에서 재현하는 방법이다.
데이터 파일은 기존과 동일하게 `aging_infra_flat.csv`(`팀원공유0826v4.zip`에 이미 있음) 하나만 쓴다.

시작 전에 `docs/PowerBI_가이드.md`의 0장(파일 불러오기 · `국가명` 조건 열 · 국가별 색 고정)을
먼저 끝내둔다. 이 문서는 그게 이미 되어 있다고 가정하고 이어서 설명한다.

## 12. 슬로프 차트 — 2015→2023 고령화율 변화 (`12_slope_aging_change.png`)

1. **꺾은선형 차트** 클릭
2. X축: `year`
3. 범례: `region_name_kr`
4. 값: `aging_rate` → 평균
5. 시각화 **필터**에 `year` 추가 → "다음 값과 같음" → **2015, 2023** 두 값만 체크
6. 시각화 **필터**에 `region_name_kr` 추가 → 필터 형식 "고급 필터링" → **다음 중 하나**로 아래 9개 지역만 입력:
   `부산광역시, 강원특별자치도, 울산광역시, 경상북도, 대구광역시, 경상남도, 아오모리현, 아키타현, 세종특별자치시`
7. 서식 → **데이터 레이블** 켜기 (지역명+값이 선 끝에 표시됨)
8. 서식 → 색: 0-4대로 국가별 색 지정

> 원본 이미지는 나머지 55개 지역을 옅은 회색 배경선으로 깔았는데, Power BI에서는 시각적 개체를
> 겹치는 방식(같은 자리에 회색 버전 하나를 뒤에 두는 식)으로 재현 가능하지만 손이 많이 갑니다.
> 팀 발표용으로는 9개 지역 강조선만으로도 충분하니 생략해도 됩니다.

## 13. Small Multiples — 주목 지역 9곳 추이 그리드 (`13_small_multiples_trend.png`)

1. **꺾은선형 차트** 클릭

## 14. 범프 차트 — 순위 흐름 (`14_bump_chart_rank.png`)

값 대신 **순위**를 그리는 게 핵심입니다. 측정값 2개를 새로 만듭니다.

```DAX
평균고령화율 = AVERAGE(aging_infra_flat[aging_rate])
```

```DAX
고령화율순위 =
RANKX(
    ALLSELECTED(aging_infra_flat[region_name_kr]),
    [평균고령화율],
    ,
    DESC
)
```

(`ALLSELECTED`를 쓰면 `year` 필터는 그대로 유지한 채 `region_name_kr`만 다시 전부 펼쳐서 그 안에서
순위를 매깁니다 — 그래서 "이 연도에 64개 지역 중 몇 위인지"가 나옵니다.)

**차트 만들기:**
1. **꺾은선형 차트** 클릭
2. X축: `year`
3. 범례: `region_name_kr`
4. 값: `[고령화율순위]` (방금 만든 측정값 — `aging_rate`가 아님!)
5. 필터: 12번과 동일한 9개 지역만
6. 서식 → **Y축** → **값 반전(Invert)** 켜기 (1위가 위로 오게)
7. 서식 → 데이터 레이블 켜기

## 15. 분해 트리 — 65세이상인구 국가→지역 분해 (`15_decomposition_tree_mock.png`)

1. 시각화 창에서 **분해 트리(Decomposition tree)** 아이콘 클릭 (AI 시각화 그룹, 나뭇가지 모양)
2. **분석(Analyze)** 필드: `elderly_pop` → 합계
3. **설명 기준(Explain by)** 필드: `국가명`, `region_name_kr` 둘 다 추가
4. 필터: `year` = 2023
5. 트리 루트 노드 오른쪽 **+** 클릭 → `국가명` 선택 (한국/일본으로 갈라짐)
6. 각 국가 노드의 **+** 클릭 → 이번엔 **"높은 값(High value)"** AI 옵션 선택 → `region_name_kr` 선택
   → 기여도가 큰 지역부터 자동으로 펼쳐집니다 (경기도, 서울특별시, 부산광역시... / 도쿄도, 오사카부...)

> 이건 그림이 아니라 **인터랙티브 기능**입니다 — 발표할 때 실시간으로 눌러가며 보여주는 용도입니다.

## 16. 워터폴 차트 — 한국 고령화율 브릿지 (`16_waterfall_kr_bridge.png`)

가장 손이 많이 가는 차트입니다. 순서대로 따라 하세요.

### 16-1. Power Query에서 그룹 열 추가

1. **홈** → **데이터 변환**
2. **열 추가** → **조건 열**, 이름 `브릿지그룹`
3. 아래 순서로 조건을 6개 추가(각 지역이 country=KR일 때만 해당 지역명, 나머지는 "나머지 11개 시도"):
   `region_name_kr` = `부산광역시` → `부산광역시`, 그렇지 않고 = `강원특별자치도` → `강원특별자치도`,
   ... (울산광역시·경상북도·대구광역시·경상남도까지 6개 동일 패턴) ...,
   그 외 모두 → `나머지 11개 시도`
4. **열 추가** → **사용자 지정 열**, 이름 `정렬순서` — 아래처럼 각 그룹에 순서 번호를 매깁니다.

```
= if [브릿지그룹] = "부산광역시" then 1
  else if [브릿지그룹] = "강원특별자치도" then 2
  else if [브릿지그룹] = "울산광역시" then 3
  else if [브릿지그룹] = "경상북도" then 4
  else if [브릿지그룹] = "대구광역시" then 5
  else if [브릿지그룹] = "경상남도" then 6
  else 7
```

5. **닫기 및 적용**
6. 필드 창에서 `브릿지그룹` 클릭 → 리본 **열 도구** → **열 기준 정렬** → `정렬순서` 선택

### 16-2. DAX 측정값 2개

```DAX
지역델타 =
VAR y23 =
    CALCULATE(
        SUM(aging_infra_flat[aging_rate]),
        aging_infra_flat[year] = 2023,
        ALLEXCEPT(aging_infra_flat, aging_infra_flat[region_name_kr], aging_infra_flat[country])
    )
VAR y15 =
    CALCULATE(
        SUM(aging_infra_flat[aging_rate]),
        aging_infra_flat[year] = 2015,
        ALLEXCEPT(aging_infra_flat, aging_infra_flat[region_name_kr], aging_infra_flat[country])
    )
RETURN y23 - y15
```

```DAX
워터폴값 =
SWITCH(
    SELECTEDVALUE(aging_infra_flat[브릿지그룹]),
    "평균(2015)", 13.8,
    "평균(2023)", 19.6,
    SUMX(VALUES(aging_infra_flat[region_name_kr]), DIVIDE([지역델타], 17))
)
```

(`13.8`, `19.6`은 실제 한국 17개 시도 평균 고령화율 값입니다 — `sql/analysis/q1.sql` 결과와
`docs/기획서.md` Insight 1에 이미 나온 검증된 숫자라 그대로 하드코딩해도 됩니다.)

### 16-3. 카테고리에 시작/끝 anchor 추가

Power Query에서 `브릿지그룹` 조건 열에 "평균(2015)"·"평균(2023)"이라는 값 자체가 없으므로,
이 두 anchor는 **워터폴 시각적 개체 안에서 직접 추가**해야 합니다 — 대신 더 간단한 방법은
`브릿지그룹`이 "부산광역시"인 아무 행 하나를 복제해서 값만 "평균(2015)"/"평균(2023)"으로 바꾼
행 2개를 Power Query에서 직접 추가하는 것입니다 (**홈 → 데이터 입력**으로 임시 2행짜리 테이블을
만들어 병합해도 됩니다). 시간이 부족하면 이 anchor 없이 6개 지역 + 나머지 막대만 보여줘도
"상위 6개 지역이 증가분의 44%를 차지한다"는 핵심 메시지는 그대로 전달됩니다.

### 16-4. 차트 만들기

1. **폭포(Waterfall)** 차트 클릭
2. 범주(Category): `브릿지그룹`
3. Y축: `[워터폴값]`
4. 필터: `country` = KR
5. "평균(2015)", "평균(2023)" 데이터 포인트를 차트에서 우클릭 → **합계로 설정(Set as total)**
