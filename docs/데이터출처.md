# 데이터 출처 (Data Sources)

`data/raw/` 아래 원본 CSV 7개(일본 3개 + 한국 4개, 이 중 1개는 미사용)의 출처를 정리한다.
전처리·적재에 실제로 쓰인 항목은 `scripts/preprocess_and_load.py`, 수집 코드는
`scripts/collect_estat_japan.py`(일본) / `scripts/collect_kosis_korea.py`(한국) 참고.

---

## 일본 (e-Stat, 総務省統計局 정부통계포털)

### 1. 인구 — `estat_A_인구세대_prefecture.csv`

- **통계명**: 人口推計(인구추계) 各年10月1日現在人口 統計表010「都道府県，年齢（5歳階級），男女別人口」
- **제공기관**: 총무성 통계국(総務省統計局)
- **성격**: 국세조사(census)를 벤치마크로 출생·사망·이동 통계를 결합해 매년 10월 1일 기준으로 발표하는 공식 추계치. (국세조사 원자료 자체는 5년 주기라 매년 분석에 쓸 수 없어 이 소스로 대체함 — `docs/원본데이터_점검.md` 2.1 참고)
- **수집 방식**: e-Stat REST API (`api.e-stat.go.jp/rest/2.1/app/json/getStatsData`), 두 census 기준연도 시리즈를 이어붙임
- **테이블(통계표) ID / 기간**:
  | 시리즈 | statsDataId | 기간 | 웹 조회 URL |
  |---|---|---|---|
  | 平成27年(2015)국세조사 기준 | `0003459027` | 2015~2019 | https://www.e-stat.go.jp/dbview?sid=0003459027 |
  | 令和2年(2020)국세조사 기준 | `0003448237` | 2020~2024 | https://www.e-stat.go.jp/dbview?sid=0003448237 |
- **사용 항목**: 男女計(cat01=000) × 総人口(cat03=001) × 연령5세계급(cat02) 중 총수(01000)와 65세이상 5개 구간(65~69/70~74/75~79/80~84/85세이상: 01014, 01015, 01016, 01017, 04018) 합산
- **단위 주의**: 원자료 단위가 **千人(천명)** — 전처리 시 ×1000으로 실인원수 환산(`collect_estat_japan.py` 2026-08-24 (3) 수정 참고)
- **지역 단위**: 47도도부현 (이미 도도부현 단위로 제공, 시구정촌 합산 불필요)

### 2. 의료 — `estat_I_의료_prefecture.csv`

- **통계명**: 社会・人口統計体系(사회·인구통계체계) 都道府県データ「Ｉ 健康・医療」
- **제공기관**: 총무성 통계국
- **포털**: https://www.e-stat.go.jp/stat-search/database?toukei=00200502
- **statsDataId**: `0000020209`
- **사용 항목(cat01)**: `I5211`(병원 병상수), `I5212`(일반진료소 병상수) — 두 항목을 합산해 `medical_beds`로 사용
- **기간**: 2015~2023 (9개년, 2024년분 아직 미공표)
- **지역 단위**: 시구정촌(市区町村) 원자료를 도도부현 단위로 합산(레벨2만 사용, 레벨3 구는 중복 제외) — `collect_estat_japan.py`의 `aggregate_to_prefecture()` 참고

### 3. 복지(장기요양) — `estat_J_복지_prefecture.csv`

- **통계명**: 社会・人口統計体系 都道府県データ「Ｊ 福祉・社会保障」
- **제공기관**: 총무성 통계국
- **포털**: https://www.e-stat.go.jp/stat-search/database?toukei=00200502
- **statsDataId**: `0000020210`
- **사용 항목(cat01)**: 개호노인복지시설 수(`介護老人福祉施設数`), 정원(`介護老人福祉施設定員数`) — 조사양식이 2018년 전후로 詳細票(J230121/J230124)→基本票(J230127/J230128)로 바뀌어 코드가 갈라진 것을 하나의 지표명으로 통합(`CAT01_NAME_UNIFY`)
- **기간**: 2015~2023 (9개년)
- **지역 단위**: 시구정촌 원자료를 도도부현 단위로 합산(estat_I_의료와 동일 방식)

### API 접근 공통 사항

- appId(API 키)는 e-Stat 회원가입(이메일 인증만 필요) 후 마이페이지 > API機能에서 발급, `.env`의 `ESTAT_APP_ID`에 저장 (커밋 금지)
- API 버전: 2.1, 엔드포인트: `https://api.e-stat.go.jp/rest/2.1/app/json/getStatsData`

## 한국 (KOSIS, 국가데이터처 국가통계포털)

### 4. 고령인구비율 — `kosis_고령인구비율.csv`

- **통계명**: 시도/시/군/구 고령인구비율
- **제공기관**: 통계청(국가데이터처, orgId=101)
- **tblId**: `DT_1YL20631`
- **웹 조회 URL**: https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1YL20631
- **사용 항목**: `65세이상인구(A)`, `전체인구(B)`, `고령인구비율(A÷B×100)`
- **기간**: 2015~2024 (10개년)
- **지역 단위**: 원자료에 전국+17개 시도+229개 시군구가 혼재 — 전처리 시 17개 시도명 정확히 일치하는 행만 필터링(`docs/원본데이터_점검.md` 2.2)

### 5. 장기요양기관현황 — `kosis_장기요양기관현황.csv`

- **통계명**: 시도별 장기요양기관 현황
- **제공기관**: 국민건강보험공단(orgId=350)
- **tblId**: `DT_35006_N019`
- **웹 조회 URL**: https://kosis.kr/statHtml/statHtml.do?orgId=350&tblId=DT_35006_N019
- **사용 항목**: `기관수`(2번째 분류축 `category2`가 "계"인 합계 행만 사용 — 방문요양/노인요양시설 등 9개 세부시설유형은 미사용). `정원`은 수집은 됐으나 현재 전처리에서 미사용.
- **기간**: 2015~2024 (10개년)
- **지역 단위**: 17개 시도 + `합계`(전국) — `합계` 행은 전처리에서 제외

### 6. 의료기관병상수 — `kosis_의료기관병상수.csv`

- **통계명**: 인구 천명당 의료기관병상수(시도/시/군/구)
- **제공기관**: 통계청(국가데이터처, orgId=101)
- **tblId**: `DT_1YL20971`
- **웹 조회 URL**: https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1YL20971
- **사용 항목**: `총병상수(A)`
- **기간**: 2015~2024 (10개년)
- **지역 단위**: 원자료에 전국+17개 시도+시군구 혼재 — 17개 시도만 필터링
- **비고**: 기획서 2.1에는 원래 "KOSIS e-지방지표(kosis.kr/visual/eRegionJipyo, themaId=A_01_03)"로 수집 예정이었으나, e-지방지표는 시각화 전용 서비스라 표준 Open API와 별개임을 확인. 같은 수치를 담은 정식 통계표(`DT_1YL20971`)를 찾아 이걸로 대체 수집함 (2026-08-24 (3) — 최초 수집에서 누락됐던 항목, `docs/원본데이터_점검.md` 2.5-1 참고).

### 7. (미사용) 주민등록인구현황 — `kosis_주민등록인구현황.csv`

- **통계명**: 주민등록인구현황(추정)
- **제공기관**: 행정안전부 계열로 추정 — 정확한 tblId는 확인되지 않음(수집 스크립트 설정에 없던 항목이 파일로만 존재해서 발견된 케이스, `docs/원본데이터_점검.md` 2.3 참고)
- **기간**: 2015~2024 (10개년)
- **사용 여부**: **미사용**. `kosis_고령인구비율.csv`의 `전체인구(B)` 항목과 총인구 수치가 중복이라 전처리 파이프라인에서 제외함. 원본 기록용으로만 `data/raw/`에 보존.

### API 접근 공통 사항

- apiKey는 KOSIS 회원가입(본인인증 필요) 후 Open API > 활용신청에서 자동 발급, `.env`의 `KOSIS_API_KEY`에 저장 (커밋 금지)
- 엔드포인트: `https://kosis.kr/openapi/Param/statisticsParameterData.do` (`method=getList`, `prdSe=Y` 연간자료)
