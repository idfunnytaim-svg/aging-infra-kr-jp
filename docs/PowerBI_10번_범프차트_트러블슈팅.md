# Power BI 10번 그래프(범프 차트) 만들기 — 트러블슈팅 정리

`최종선정그래프/10_고령화율_지역순위_범프.png`를 Power BI 네이티브(꺾은선형 차트 + DAX 순위)로
재현하는 방법입니다. 기본 레시피는 `docs/PowerBI_가이드_0827.md`의 14번 항목과 같고, 이 문서는
실제 작업 중 겪은 에러(순위가 다 1로 뜨는 문제 등)의 원인과 해결 과정을 포함해 정리한 버전입니다.

> ⚠️ 시작 전에 `docs/PowerBI_가이드.md`의 0장(파일 불러오기 등)이 끝나 있어야 합니다.

## 1. 순위 측정값 2개 만들기

```dax
평균고령화율 = AVERAGE(aging_infra_flat[aging_rate])
```

```dax
고령화율순위 =
RANKX(
    ALLSELECTED(aging_infra_flat[region_name_kr]),
    [평균고령화율],
    ,
    DESC
)
```

**반드시 "새 측정값(New Measure)"으로 만들 것 — "새 열(New Column)"로 만들면 안 됨.**

### 왜 계산된 열로 만들면 순위가 전부 1로 뜨는가

순위(rank)는 "지금 화면에 어떤 연도·어떤 지역이 보이는지"에 따라 계속 달라져야 하는 값인데,
계산된 열은 데이터가 새로고침될 때 딱 한 번만 계산되고 그 시점에는 화면(시각화) 자체가 없습니다.
`ALLSELECTED`는 "지금 화면에서 선택된 필터 상태"를 참조하는 함수라서, 계산된 열 안에서 쓰면
의도대로 동작하지 않고 모든 행이 같은 값으로 묶여 순위가 전부 1(공동 1위)로 나옵니다.
→ 해결: 열을 지우고 **측정값**으로 다시 만들면, 시각화에 올라갈 때마다 그 시점의 연도·지역
컨텍스트를 실시간으로 인식해서 순위를 다시 계산합니다.

`ALLSELECTED`를 쓰면 `year` 필터는 그대로 유지한 채 `region_name_kr`만 다시 전부 펼쳐서 그 안에서
순위를 매깁니다 — 그래서 "이 연도에 64개 지역 중 몇 위인지"가 나옵니다.

## 2. 차트 만들기

1. **꺾은선형 차트(Line chart)** 선택
2. X축: `year`
3. **범례(Legend)**: `region_name_kr` (이게 있어야 지역별로 선이 따로 그려짐)
4. 값: **`[고령화율순위]`** ← `aging_rate`가 아니라 위에서 만든 순위 측정값을 넣어야 함

---

## 3. 9개 지역만 남기기 (전체 64개가 다 보이는 문제 해결)

시각적 개체 **필터**에 `region_name_kr` 추가 → 필터 형식 "고급 필터링" → **다음 중 하나**로
아래 9개만 입력:

```
부산광역시, 강원특별자치도, 울산광역시, 경상북도, 대구광역시, 경상남도, 아오모리현, 아키타현, 세종특별자치시
```

한국 고령화 증가폭 TOP6 + 일본 증가폭 TOP2 + 세종(대조군) = 9개
(`scripts`의 원본 파이썬 로직과 `docs/PowerBI_가이드_0827.md` 12번 항목에 이미 확정된 목록)

---

## 4. 색을 한국/일본으로 구분하기

범례가 `region_name_kr`이라 서식 > 데이터 색에 **지역 이름 9개**가 계열로 뜹니다. 국가별 2색으로
고정하려면 9개를 하나씩 수동으로 칠해야 합니다 (서식 페인트 롤러 → 시각적 개체 탭 → 데이터 색):

| 색 | 지역 |
|---|---|
| 파랑 `#2A78D6` | 부산광역시, 강원특별자치도, 울산광역시, 경상북도, 대구광역시, 경상남도, 세종특별자치시 (7개, 전부 한국) |
| 주황 `#EB6834` | 아오모리현, 아키타현 (2개, 전부 일본) |
