## 20. 연도별 인프라밀도 추이 — "막대 말고 다른 그래프로" (`20_infra_density_trend.png`)

기존 04번(국가별 인프라 밀도, 막대·2023년 단일시점)을 시간 흐름이 보이는 **꺾은선형 차트**로 교체.

**왼쪽 차트 (병상수):**
1. **꺾은선형 차트** 클릭
2. X축: `year` (필터 없음, 2015~2023 전체)
3. 범례: `국가명`
4. 값: `medical_beds_per_10k` → 평균
5. 서식 → 범례 위치를 **아래쪽(Bottom)** 이나 **오른쪽 아래**로 — 값이 우상향이라 기본 위치(위쪽)에 두면 선과 겹침

**오른쪽 차트 (요양기관수):** 값만 `care_facility_per_10k` → 평균으로 바꿔서 동일하게 하나 더 생성.

## 21. 국가별 고령화·인프라 지표 — "나눠서 막대그래프로" (`21_indicators_by_country.png`)

고령화율(%)·병상수(개)·요양기관수(개)는 단위가 완전히 달라 막대 하나에 같이 그리면 왜곡됩니다.
그래서 **한국 행 / 일본 행 × 지표 3개 열**로 나눈 카드 6개(또는 미니 막대 6개)로 구성합니다.

**카드로 만들 때(권장, 더 깔끔함):**
1. 카드 6개를 반복해서 만듭니다. 값 필드와 필터만 아래 표대로 바꿔가며 복사-붙여넣기.

| 카드 | 값 | 필터 |
|---|---|---|
| 한국-고령화율 | `aging_rate` 평균 | `country`=KR, `year`=2023 |
| 한국-병상수 | `medical_beds_per_10k` 평균 | `country`=KR, `year`=2023 |
| 한국-요양기관수 | `care_facility_per_10k` 평균 | `country`=KR, `year`=2023 |
| 일본-고령화율 | `aging_rate` 평균 | `country`=JP, `year`=2023 |
| 일본-병상수 | `medical_beds_per_10k` 평균 | `country`=JP, `year`=2023 |
| 일본-요양기관수 | `care_facility_per_10k` 평균 | `country`=JP, `year`=2023 |

2. 2행(한국/일본) × 3열(지표) 그리드로 캔버스에 배치 → 원본 이미지와 동일한 레이아웃

**막대그래프로 만들 때(대안):**
지표별로 **묶은 세로 막대형 차트**를 3개 만들고, 각 차트의 X축을 `국가명`으로 두면 됩니다
(=기존 03번·04번과 똑같은 방식, 지표만 3개로 늘어난 것). 카드보다 손이 덜 가지만
"행으로 분리"된 느낌은 카드 쪽이 더 강합니다.

## 22. 지역별 고령화율 TOP 10 (단일) — "10개로 통일" (`22_region_top10_aging.png`)

기존 06번(상위10 + 하위10, 차트 2개)에서 **하위 10개 차트를 빼고 상위 10개 하나만** 남깁니다.

1. **가로 막대형 차트** 클릭
2. Y축: `region_name_kr`
3. 값: `aging_rate` → 평균
4. 범례: `국가명`
5. 필터: `year` = 2023, **그리고** `aging_rate` 필터 추가 → 필터 형식을 **상위 N** → 10
6. 축 정렬: `aging_rate` 내림차순

(06번을 이미 만들어뒀다면 그 차트를 복제한 뒤 하위 10개짜리 사본만 캔버스에서 삭제하면 끝입니다.)

## 23. 고령화율 증가폭 — 국가별 TOP5 (`23_increase_top5_by_country.png`)

기존 10번(TOP15 통합, 한국 지역이 싹쓸이해서 일본이 캡션에만 나옴)을 보완 — 국가별로 따로 TOP5.

`docs/PowerBI_가이드.md` **4-2**에서 만든 `증가폭_2015_2023` 계산 열이 있으면 그대로 재사용하세요.
없다면 먼저 추가:

```DAX
증가폭_2015_2023 =
VAR y2023 =
    CALCULATE(
        SUM(aging_infra_flat[aging_rate]),
        aging_infra_flat[year] = 2023,
        ALLEXCEPT(aging_infra_flat, aging_infra_flat[region_name_kr], aging_infra_flat[country])
    )
VAR y2015 =
    CALCULATE(
        SUM(aging_infra_flat[aging_rate]),
        aging_infra_flat[year] = 2015,
        ALLEXCEPT(aging_infra_flat, aging_infra_flat[region_name_kr], aging_infra_flat[country])
    )
RETURN y2023 - y2015
```

**차트 만들기(한국용):**
1. **가로 막대형 차트** 클릭
2. Y축: `region_name_kr`
3. 값: `증가폭_2015_2023` → 평균 (지역당 값이 하나뿐이라 평균 해도 그 값 그대로)
4. 필터: `country` = KR, **그리고** `증가폭_2015_2023` 필터 → 상위 N = 5
5. 축 정렬: 내림차순

같은 차트를 복제해서 필터만 `country` = JP로 바꾸면 일본용 TOP5가 나옵니다. 두 차트를 나란히 배치.
