# 2.5 ERD

​

다음과 같이 테이블 간 관계를 설계한다.

​

```text

             ┌──────────────┐

             │  Dim_Customer│

             │--------------│

             │ customer_id PK│

             │ customer_name │

             │ age           │

             └───────┬──────┘

                     │ 1:N

                     │

┌──────────────┐     │     ┌──────────────┐

│ Dim_Product  │     │     │ Dim_Date     │

│--------------│     │     │--------------│

│ product_id PK│     │     │ date_id PK   │

│ product_name │     │     │ year         │

│ category     │     │     │ month        │

└───────┬──────┘     │     │ quarter      │

        │            │     └───────┬──────┘

        │ 1:N        │             │ 1:N

        └────────────┼─────────────┘

                     │

               ┌─────▼─────┐

               │   Fact    │

               │-----------│

               │ date_id FK│

               │ customer_id FK

               │ product_id FK

               │ amount    │

               │ quantity  │

               └───────────┘
```
