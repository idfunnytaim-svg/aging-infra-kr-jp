## 0. 먼저 할 일 — Python 시각화 켜기 (한 번만)

   설치돼 있으면 명령 프롬프트에서 `pip install pandas matplotlib`로 두 패키지를 넣어주세요.
2. Power BI Desktop → **파일 → 옵션 및 설정 → 옵션 → Python 스크립팅** → 위에서 설치한
   Python 실행 파일 경로를 지정합니다.
3. 이제 **시각화 창 → "Python 시각적 개체"(뱀 모양 아이콘)** 를 캔버스에 추가할 수 있습니다.

## 2. 사용법 (10개 공통)

1. Power BI 캔버스에 **Python 시각적 개체**를 하나 추가합니다.
2. 각 스크립트 상단 주석에 적힌 **필드 표**대로 `필드` 창에서 드래그해 넣습니다. 이때 각
   필드 칩을 **더블클릭해서 표시 이름을 표에 적힌 대로 정확히 바꿔주세요**
   (예: `Dim_Region.region_name_kr` → `region_name_kr`) — 코드가 이 이름을 그대로 씁니다.
3. 필요하면 스크립트 상단에 적힌 **시각적 개체 필터**(연도 등)도 걸어주세요.
4. Python 시각적 개체 아래쪽 **코드 편집기**를 펼치면 이미 아래 두 줄이 자동으로 들어가 있습니다
   — **이 두 줄은 지우지 말고**, 그 밑에 해당 `.py` 파일 내용을 전체 복사해서 붙여넣으세요.
   ```python
   # dataset = pandas.DataFrame(...)
   # dataset = dataset.drop_duplicates()
   ```
5. 오른쪽 위 ▶(스크립트 실행) 버튼을 누르면 그래프가 그려집니다.

### ★ 공통 규칙 — `region_name_kr`은 항상 넣기

10개 스크립트 전부 `Dim_Region[region_name_kr]`을 필드에 넣도록 안내합니다. 이걸 빼면
Power BI가 국가 단위로 값을 먼저 SUM해서 넘겨버려(예: "인구 1만명당 병상수" 같은 평균
지표가 국가 내 지역 수만큼 부풀려짐) 코드의 계산이 틀어집니다. **평균·합계·순위 같은
집계는 전부 코드(pandas) 안에서 직접 계산**하도록 짜여 있으니, Power BI 쪽 필드는
항상 지역 단위 원자료 그대로 넘어오게만 해주면 됩니다.

## 3. 04번(재생축)은 코드 대신 네이티브 기능도 검토해보세요

Power BI 분산형(Scatter) 차트는 **재생 축(Play Axis)** 필드를 기본 제공합니다. 아래처럼
필드만 꽂으면 코드 없이도 ▶버튼으로 2015→2023 애니메이션이 자동 재생되는데, 정지 이미지
필름스트립보다 발표 효과가 더 좋을 수 있습니다.

- X축: `aging_rate`, Y축: `medical_beds_per_10k`(+`care_facility_per_10k`를 더한 측정값을
  하나 새로 만들면 더 정확), 범례: `country`, 크기: `total_pop`, **재생 축**: `Dim_Date[year]`

`19_playback_scatter_python_visual.py`는 이 네이티브 기능을 못 쓰는 환경(구버전 Power BI,
PPT에 정지 이미지로 박아야 하는 경우 등)에서만 쓰면 됩니다.

## 4. 알려진 제약

- Python 시각화는 **정적 이미지**입니다 — 다른 차트를 클릭해도 같이 하이라이트되는
  상호 필터링(cross-filter)이 안 됩니다.
- 데이터나 필터가 바뀌면 **자동으로 다시 그려지지 않을 수 있어** 오른쪽 위 ▶ 버튼을
  다시 눌러줘야 할 때가 있습니다.
- 값 검증: 07·09번(인프라 격차지수) 스크립트는 실제 `aging_infra.db`로 재계산해본 결과
  한국 최우선 지역 강원특별자치도 -9, 일본 최우선 지역 야마가타현 -21로 기존 검증값과
  정확히 일치함을 확인했습니다.

## 5. 문제 해결

- **한글이 네모(□)로 깨질 때**: 스크립트 상단에 이미 맑은 고딕(Windows 기본 폰트)을 자동
  등록하는 코드가 들어있습니다. 그래도 깨지면 이 PC에 맑은 고딕이 없는 것이니
  `C:\Windows\Fonts` 안의 한글 지원 폰트 이름으로 `font.sans-serif` 목록 첫 항목을 바꿔보세요.
- **`KeyError: 'region_name_kr'` 같은 에러가 날 때**: 필드 표시 이름이 표와 다르게 들어간
  경우입니다 — 필드 칩을 더블클릭해서 정확한 이름으로 다시 바꿔주세요.
- **그래프가 비어있거나 이상할 때**: 시각적 개체 필터(연도 등)가 안 걸려 있거나 잘못
  걸려 있는 경우가 많습니다 — 각 스크립트 상단 주석의 필터 조건을 다시 확인하세요.
- **평균/합계 값이 이상하게 크거나 이상할 때**: `region_name_kr` 필드를 빼먹은 경우입니다
  — 위 "공통 규칙" 참고.
