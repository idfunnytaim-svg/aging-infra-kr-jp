# Power BI 그래프 예쁘게 만들기 가이드

이 문서는 "지금 있는 그대로도 데이터는 맞는데 왜 안 예뻐 보이는가"에 대한 답과, 실제로 손댈 수 있는 순서를 정리한 것입니다. 이미 만든 10개 그래프(`최종선정그래프/PowerBI_가이드_최종.md`)의 시각적 개체·필드 배치는 그대로 두고, **디자인만** 다듬는 것이 목적입니다.

## 지금 안 예뻐 보이는 이유 (진단)

Power BI 기본 상태로 만든 대시보드가 어설퍼 보이는 이유는 대부분 아래 4가지 중 하나입니다.

1. **색이 자동 배정됨** — 필드를 넣으면 Power BI가 파란/노랑/초록/보라를 임의로 섞어 배정합니다. 우리 프로젝트는 이미 Python 그래프(`figures/`, `최종선정그래프/`)에서 **한국=파랑, 일본=주황**으로 색을 고정해뒀는데, Power BI에서 손으로 다시 만들면 이 색이 안 맞아서 "같은 프로젝트인데 그림마다 색이 다른" 느낌이 납니다.
2. **여백·정렬이 안 맞음** — 카드/차트를 눈대중으로 배치하면 크기가 미묘하게 다르고 줄이 안 맞습니다. 사람 눈은 이런 어긋남에 민감합니다.
3. **기본 테두리·그리드선이 그대로 있음** — Power BI 기본값은 모든 시각적 개체에 테두리, 배경 그림자, 촘촘한 격자선이 다 켜져 있어서 화면이 시끄러워 보입니다.
4. **글꼴 크기·색이 시각적 개체마다 제각각** — 제목은 크게, 축은 작게, 이런 위계가 없으면 뭘 먼저 봐야 할지 눈이 헤맵니다.

넷 다 "안목"의 문제가 아니라 **설정값의 문제**라서, 아래 순서대로 몇 번 클릭하면 눈에 띄게 달라집니다.

## 0단계. 테마 파일 적용 (가장 효과가 큼, 5분)

이 zip에 동봉한 `PowerBI_테마_고령화인프라.json`은 우리 프로젝트 Python 그래프와 **완전히 같은 색상 값**(한국 `#2a78d6` 파랑 / 일본 `#eb6834` 주황 / 배경 `#fcfcfb`)으로 만든 Power BI 테마 파일입니다. 이것만 적용해도 "색이 중구난방" 문제는 바로 해결됩니다.

적용 방법:
1. Power BI Desktop에서 **보기(View) 탭 → 테마(Themes) → 테마 찾아보기(Browse for themes)**
2. 동봉한 `PowerBI_테마_고령화인프라.json` 선택
3. 모든 시각적 개체 색이 한 번에 파랑/주황 계열로 바뀌는지 확인

이후 새로 만드는 차트는 자동으로 이 색을 씁니다. 단, 이미 만든 차트 중 색을 손으로 직접 지정해둔 게 있다면 테마가 덮어쓰지 못하니, 그런 차트는 아래 1단계 방식으로 다시 맞춰줘야 합니다.

## 1단계. 국가별 색을 필드값에 직접 고정

테마를 입혀도 "국가"처럼 카테고리가 여러 개인 차트는 어떤 값에 어떤 색이 갈지 자동 배정될 수 있습니다. 확실하게 하려면:

1. 차트 선택 → **서식(Format) 창 → 셀 요소(Data colors)**
2. "모두 표시(Show all)" 켜기
3. `한국` 항목 → `#2a78d6`, `일본` 항목 → `#eb6834`로 직접 지정

이걸 대시보드의 모든 차트에 반복하면, 어떤 페이지를 봐도 "파란 게 한국, 주황이 일본"이라는 게 즉시 읽힙니다 — 지금까지 Insight에서 강조해온 한/일 비교 스토리와도 맞아떨어집니다.

## 2단계. 군더더기 제거

기본값 중 꺼도 되는 것들 (서식 창에서 각각 토글):

- **테두리(Border)**: 끄기 — 카드/차트 사이는 여백만으로 구분되게
- **배경 그림자(Shadow)**: 끄기
- **가로/세로 눈금선(Gridlines)**: 꼭 필요한 경우(추이선 차트 등)만 남기고, 연한 회색(`#e1e0d9`)으로 두껍지 않게
- **범례(Legend)**: 시리즈가 1개뿐인 카드/차트는 범례 자체를 끄기 (안 그러면 "한국"이라는 글자가 쓸데없이 한 줄 차지함)
- **데이터 레이블 소수점**: 고령화율은 소수점 1자리(`19.6%`), 인구수 같은 큰 숫자는 천 단위 구분(`1,234,567`) — 서식 창 → 데이터 레이블 → 값 서식 지정에서 통일

## 3단계. 정렬 · 여백

- 시각적 개체 여러 개를 선택한 뒤 **서식(Format) 탭 → 맞춤(Align) / 배분(Distribute)** 을 쓰면 눈대중보다 훨씬 깔끔하게 줄이 맞습니다.
- 페이지 안에서 카드 4개처럼 같은 종류가 반복되면 크기를 완전히 똑같이(같은 폭·높이) 맞추세요. 하나의 시각적 개체 크기·위치를 서식 창에서 숫자로 확인하고, 나머지에 똑같이 입력하면 정확히 맞습니다.
- 차트 사이 여백은 너무 붙이지 말고 일정한 간격(예: 8~10px)을 반복하세요. "빽빽함"보다 "여백이 규칙적인 것"이 더 정돈돼 보입니다.

## 4단계. 글꼴 위계 통일

- 페이지 제목: 16~20pt, 굵게
- 차트 제목: 12~14pt, 굵게
- 축 레이블·범례: 9~10pt, 일반
- 전체 글꼴은 한 종류로 통일(기본 Segoe UI로 충분, 여러 폰트 섞지 않기)

이건 각 차트마다 손으로 맞추는 것보다, 위 0단계 테마 JSON의 `visualStyles`에 폰트 규칙을 추가해서 한 번에 적용하는 방법도 있습니다 — 필요하면 다음에 요청해주시면 확장해드리겠습니다(지금 동봉한 버전은 색상·배경·테두리 제거까지만 포함).

## 5단계. 카드(KPI) 디자인 통일

지금 페이지 1(Overview)의 평균 고령화율/인구증감률/병상수/요양기관수 카드 4개가 서로 다른 스타일이 되지 않도록:

- 카드 배경색·테두리·숫자 글꼴 크기를 4개 다 동일하게
- 카드 안 아이콘을 쓴다면(예: 사람 모양, 병원 모양) 같은 아이콘 세트(예: Fluent UI 아이콘)에서만 골라서 스타일이 섞이지 않게

## 6단계. 정렬 순서

막대차트의 카테고리(지역명 등)는 **알파벳/가나다 순이 아니라 값 기준 내림차순**으로 정렬하세요 — 시각적 개체 우측 상단 `...` 메뉴 → 축 정렬(Sort axis) → 값 기준. TOP10 랭킹 차트에서 특히 중요합니다(이미 그렇게 만든 차트는 그대로 두면 됩니다).

## 마무리 체크리스트

- [ ] 테마 JSON 적용함
- [ ] 모든 차트에서 한국=파랑/일본=주황 고정됨
- [ ] 테두리·그림자·불필요한 범례 껐음
- [ ] 카드 4개 크기·스타일 통일함
- [ ] 제목/축 글꼴 크기 위계 통일함
- [ ] 막대차트 정렬 순서 값 기준으로 확인함

이 6단계만 해도 "데이터는 맞는데 손을 안 댄 느낌"에서 "다듬어진 대시보드"로 체감이 꽤 큽니다. 색상표 자체를 다른 톤(예: 더 어둡게, 파스텔 톤 등)으로 바꾸고 싶으면 알려주시면 테마 JSON도 그에 맞춰 다시 만들어드릴 수 있습니다.
